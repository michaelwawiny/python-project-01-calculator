# Python Calculator

A command-line calculator built using Python 3.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Exponentiation
- Modulus
- Input validation
- Error handling
- Continuous calculations
- Exit option

## Technologies Used

- Python 3

## How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run:

   python3 calculator.py

## Example

```text
PYTHON CALCULATOR

1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Exponentiation (**)
6. Modulus (%)
0. Exit
```
